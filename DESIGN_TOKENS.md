# RapidEx Quote Desk — Design System

All UI must match the live RapidExpress website:
https://www.rapidexpress.pk/

Before building UI, inspect the site’s rendered HTML/CSS and extract:
- Primary, secondary, accent, background, surface, text, muted-text, border, and divider colors
- Font family, weights, sizes, line heights
- Button, card, form, badge, modal, toast, and icon styles
- Border radius, shadows, spacing, and max content width

Rules:
- Match RapidEx exactly; do not invent a new brand identity.
- No generic purple/indigo SaaS theme, heavy gradients, or placeholder branding.
- Public quote form must match RapidEx’s existing forms and CTAs.
- Internal dashboard may be data-dense but must use the same brand palette and components.
- Mark any unverifiable style as “inferred.”
- Fully responsive and accessible.
